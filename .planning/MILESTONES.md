# Milestones

## v0.1 Initial Release (Shipped: 2026-07-14)

**Phases completed:** 8 phases, 66 plans, 142 tasks

**Delivered:** a working Go rewrite of CodeGraph's core capabilities — from-scratch indexing, a read-only query engine + stdio MCP server (output shapes verified against the TS v1.3.1 golden corpus), incremental sync + daemon, 14-language coverage, agent install/uninstall, a TS→Pebble migration tool, and a signed/attested/SBOM'd/reproducible release (proven end-to-end on `v0.0.0-rc.3`) with published head-to-head benchmarks (Go beats TS 1.3.1 on every measured metric). **Not yet a drop-in parity replacement** — the CLI surface diverges from TS CodeGraph, so full command-surface parity remains a goal for a later release. Versioned **0.1** deliberately: functional and signed, but pre-1.0 (interface still evolving, parity incomplete).
