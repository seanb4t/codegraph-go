### `Taskfile.yml` — `check:changie` target (utility, request-response / live-tool guard)

**Analog:** `docs:cli:drift` (`Taskfile.yml:494-535`, full target — already read in its entirety, no re-read needed) — this is the EXACT shape D-07 specifies copying.

**Full core pattern to copy** (`Taskfile.yml:494-535`):
```yaml
docs:cli:drift:
  desc: >-
    DOCS-05's docs/CLI-REFERENCE.md drift guard (D-03), mirroring
    proto:drift's shape: regenerates with the SAME pinned toolchain into a
    TEMPORARY directory, never in place, so a developer's uncommitted
    edit survives a guard run untouched. Reports `compared N generated
    file` BEFORE comparing anything, and fails with a named error when N
    is below the floor of 1, so a broken enumeration can never read as a
    clean pass (rule 84d1gfpywd). A header-only or whitespace-only
    difference IS drift. Wired into ci.yml's test job immediately after
    proto:drift (D-14).
  preconditions:
    - sh: command -v go
      msg: "go not found — docs:cli:drift runs the generator via go run, same as docs:cli."
    - sh: command -v git
      msg: "git not found — docs:cli:drift enumerates the committed generated file via git ls-files."
  cmds:
    - |
      set -euo pipefail
      scratch=$(mktemp -d)
      trap 'rm -rf "${scratch}"' EXIT

      files=$(git ls-files -- 'docs/CLI-REFERENCE.md')
      ndocs=0
      if [ -n "${files}" ]; then
        ndocs=$(printf '%s\n' "${files}" | wc -l | tr -d ' ')
      fi
      echo "docs:cli:drift: compared ${ndocs} generated file"
      if [ "${ndocs}" -lt 1 ]; then
        echo "::error::docs:cli:drift: enumerated only ${ndocs} committed generated file at docs/CLI-REFERENCE.md (expected exactly 1) — a broken enumeration must fail loud, never read as a clean pass"
        exit 1
      fi

      GOTOOLCHAIN=go1.26.6 go run ./tools/clidoc -out "${scratch}/CLI-REFERENCE.md"

      if ! cmp -s docs/CLI-REFERENCE.md "${scratch}/CLI-REFERENCE.md"; then
        echo "::error::docs:cli:drift: docs/CLI-REFERENCE.md differs from a fresh regeneration by the pinned toolchain — run \`task docs:cli\` and commit the result"
        diff -u docs/CLI-REFERENCE.md "${scratch}/CLI-REFERENCE.md" | head -40 || true
        exit 1
      fi

      echo "docs:cli:drift: docs/CLI-REFERENCE.md byte-identical to a fresh regeneration (temporary file only — source tree untouched)"
```

**How `check:changie` maps this shape onto D-07's six checks:**
- `mktemp -d` scratch dir + `trap ... EXIT` — copy `.changie.yaml` and `.changes/{header.tpl.md,v*.md,unreleased/.gitkeep}` into it (never mutate the real tree — same discipline as `docs:cli:drift`/`proto:drift`).
- Count-before-compare: `echo "check:changie: verified N seeded version files"` where N is the count of `.changes/v*.md`, floor 14 — fail with `::error::` if below floor, exactly like `ndocs`'s `-lt 1` check above.
- Each of the six live checks (from RESEARCH.md D-07 / Validation Architecture) gets its own named `::error::` on failure, asserting the exact stderr substring, never a bare exit code (rule `84d1gfpywd`; RESEARCH.md Anti-Pattern: "Trusting a green exit code... as proof of anything"):
  1. `changie latest` == `v0.14.0`
  2. `changie next auto` (empty `unreleased/`) exits non-zero AND stderr contains `no unreleased changes found for automatic bumping`
  3. `changie merge --dry-run | cmp - CHANGELOG.md` (byte-identity)
  4. `CI=true changie new -k Fixes -b "…" -m PR=1` writes exactly one `.changes/unreleased/*.yaml`
  5. `changie new` with no `-m PR=` refused, stderr contains `custom missing and prompt is disabled: custom key 'PR'`
  6. `changie new -k Undeclared …` refused, stderr contains `invalid kind: Undeclared`
- Ordering constraint (D-07/Claude's Discretion): `merge --dry-run` (read-only) must run before any `changie new` invocation in the scratch copy, since `new` mutates `unreleased/`.
