Close MAINT-01 and MAINT-02 at their shared cause: `internal/daemon` tests spawn
`Daemon.Run` on a bare goroutine and never join it, so when a fixed wall-clock deadline
blows under full-suite contention, `t.Fatalf`'s `runtime.Goexit()` unwinds the test and
runs its deferred restores while that goroutine is still alive and still reading the
package-level variables the test just wrote back.

the instrument to prove a fix already exists — a fix is proven when that rate goes to zero,
not when one run passes.

spawn site, and a before/after failure-rate table.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| test harness → daemon process state | tests drive `Daemon.Run`, which acquires the repo lockfile and writes the global daemon registry under the user's home directory; a seam pointed at the wrong place would touch real state |
| spawned goroutine → package-level variable | an orphaned goroutine outliving its test reads variables a later, unrelated test writes |
| daemon → single-writer store invariant | `Run` releases the lock only after every flush has joined (INDX-05, SYNC-06); the tests asserting that are the only enforcement |
