## Intended-RED `web:drift` window (opened here, closed by 03-09)

**This is a scheduled consequence, not a defect. Do not relax, skip or narrow
`task web:drift` to make it green earlier.**

`.github/workflows/ci.yml:164` runs `task web:drift` in the `test` job on every
push. `web_source_files()` (`Taskfile.yml:40-51`, read during this revision)
enumerates `web/src`, `web/static`, `web/package.json`, `web/pnpm-lock.yaml`,
`web/pnpm-workspace.yaml`, `web/vite.config.ts`, `web/tsconfig.json` and
`web/components.json`. This plan modifies `web/package.json`,
`web/pnpm-lock.yaml` and `web/vite.config.ts`; every later web-touching plan in
this phase modifies `web/src`. The committed bundle under `web/build/` is NOT
rebuilt until **plan 03-09, Task 3**. So from the moment this plan lands until
03-09 lands, `web:drift`'s source digest and its committed output digest
disagree and the CI `test` job fails on that leg.

Note that `web/tests/` is deliberately absent from `web_source_files()`, so the
test files themselves do not churn the digest — only `package.json`,
`pnpm-lock.yaml` and `vite.config.ts` do, which is why the window opens in THIS
plan rather than in 03-04.

| | |
|---|---|
| Window opens | this plan (wave 1), at the `web/package.json` + `web/vite.config.ts` commit |
| Window closes | plan **03-09 Task 3**, at `task web:build` + the re-committed `web/build/` |
| Red leg | the `web:drift` step of the `test` job in `.github/workflows/ci.yml` |
| Expected other legs | every OTHER leg of the `test` job stays green throughout; a second red leg is a real regression, not this window |

Deliberately NOT mitigated by rebuilding the bundle at the end of each
web-touching plan: that would commit six intermediate copies of a
supply-chain artifact that is embedded in the signed release binary, each of
which would then need its own review, to avoid one leg being red on a branch
that is not being released. The honest, cheaper answer is to write the window
down. Task 3 records the window's opening in the SUMMARY, and 03-09 Task 3
records its closing.
