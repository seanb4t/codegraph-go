<objective>
Resolve GRF-01. Measure the shipped graph view against the pass condition locked in
05-01, record the result as a committed artifact next to this project's existing
recorded-measurement artifacts, and let that record — not a preference — decide
whether the phase's remaining work proceeds.

This is the blocking within-phase gate the ROADMAP names. Everything before it built
the instrument; nothing after it runs until this plan writes a verdict. D-02 is
explicit that a failure here must be reachable and actionable rather than treated as
impossible, so the failure path is not a footnote: a missed bar halts the phase and
escalates with the two remedies the threshold artifact already committed to, and
adjusting the threshold is not among them.

The comparison itself is committed code rather than a judgement call, and it fails
closed. A metric that is absent, non-numeric, or unreadable is a FAIL — because the
single most likely way this gate produces a wrong answer is a measurement that
quietly did not happen being read as a measurement that quietly passed.

Three mechanisms make that more than a claim, and all three answer the cross-AI
review's principal finding across its two cycles.

First, `web/scripts/graph-measure.mjs` OWNS the browser session and writes the raw
observation from a `finally` block, so a session that THROWS at launch, at
navigation, while polling the seam, or mid-sample still leaves a reason-bearing
artifact behind.

Second — and this is the half the first revision left open — every awaited browser
operation is raced against a rejecting deadline whose budget comes from the locked
`measurementProtocol` block. A `finally` runs on SETTLEMENT. A launch, a
navigation, a seam poll or a frame sampler that never settles never reaches it, and
the process simply holds until something outside this plan kills it — at which point
there is no artifact, the comparator never runs, and the phase's blocking gate stalls
with no recorded verdict. That is the same absent-answer outcome the `finally` was
added to prevent, reached by a different road. The `finally` closes the crash; the
deadline closes the hang; neither closes both, and a guard that only proves the
`finally` exists proves nothing about the hang.

Second-and-a-half, because the third review cycle found the second mechanism true but
unproven and one road still open. The operations are INJECTED, which is what makes
them testable — and it is also what made the coverage guard vacuous: a search for
awaits on the browser and page handles reported zero because the live path never names
those handles at a call site, whether or not a single deadline existed. Coverage is
now asserted structurally instead. The operations are an enumerated, closed set of six
spanning SETUP, the measured work and TEARDOWN; the session runner refuses any injected
object that is not exactly that set; and one never-settling case per member reads the
written artifact back and asserts the labels set-equal the enumeration. Teardown is in
that set because it was in no list at all before, and a `finally` that awaited a wedged
cleanup before writing would have consumed the artifact with every count still green.
The observation is therefore written to disk BEFORE any cleanup is awaited, and the
sweep is proven red against a copy of the script missing exactly one deadline — not
merely against one with the mechanism torn out entirely.

Third, a FAIL is a SUCCESSFUL outcome of this plan's verification: the verify command
accepts a well-formed FAIL and rejects only an artifact that is missing,
self-contradictory, or judged against the wrong corpus. A gate that could not durably
record its own worst case would be a gate in name only.

Purpose: turn the phase's blocking gate from an intention into a record.
Output: a fail-closed verdict script and an always-records measurement wrapper, both
with tests, and `corpora/graph-render-observations.json` carrying every measured
value beside the bar it was judged against — including when the measurement failed.
</objective>
