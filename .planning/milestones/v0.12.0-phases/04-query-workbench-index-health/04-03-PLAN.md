<objective>
Put every value the health view needs on the wire, as one new additive read-only
rpc, without touching the cheap per-navigation `GetStatus` message.

`internal/query.StatusResult` already computes all of it — `FilesByLanguage`,
`Languages`, `NodesByKind`, `EdgesByKind`, `DbSizeBytes`, `PendingChanges`,
`Index` and `WorktreeMismatch` (`internal/query/status.go:47-65`). `GetStatusResponse`
exposes nine scalars and none of those. **The gap is the wire, not the engine**, so
this plan is a mapping layer following the existing `statusToProto` convention —
not new engine work.

`GetStatus` stays cheap because Phase 3's `createStatusGate` fetches it on every
navigation. Adding per-language maps, per-kind maps and worktree detection to that
message would put the health page's entire cost on every click in the application
(D-01). The split is the standard health-endpoint discipline: a cheap frequently-polled
signal, and a separate diagnostic endpoint.

**The rpc is named `GetHealth`, and that is load-bearing, not cosmetic.**
`internal/uiserver/readonly_test.go:89-93` defines `mutatingVerbs`, a literal
fixture applied with a bare `strings.Contains` over every `UIServiceHandler` method
name, and it contains the literal `"Index"`. Any rpc name embedding that substring
fails `TestUIServiceDeclaresNoMutatingMethod` on first run. The guard is correct —
it is deliberately the negative half of a complementary pair with the positive
set-equality test, and it asserts a positive count of inspected names before
applying the verb check, citing rule `84d1gfpywd` in its own comment. Rename the
rpc; never weaken the guard.

Purpose: HLT-01, HLT-02 and HLT-03 are all unbuildable until this data crosses the wire.
Output: an eleventh read-only rpc, its handler and mapper, regenerated Go and
TypeScript clients, and the two load-bearing test literals updated in the same commit.
</objective>

  <behavior>
    - A `GetHealth` call against an initialized store returns a response whose
      `files_by_language`, `nodes_by_kind` and `edges_by_kind` maps equal the
      corresponding `query.StatusResult` maps entry-for-entry.
    - `languages`, `version`, `file_count`, `node_count`, `edge_count`,

    - `commit_sha` carries the indexed commit when the stored `Meta` holds a

      is well-formed" holds at every exit.
    - `worktree_mismatch` is non-nil with both roots populated when the Engine
      detects one, and nil otherwise.
    - A locked or absent store produces the ordinary `withEngine` error
      translation — `GetHealth` does not degrade-and-answer.
    - Reflection over `uiv1connect.UIServiceHandler` observes exactly eleven
      method names, and none of them contains a mutating verb substring.
