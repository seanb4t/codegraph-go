<objective>
Rewrite the MCP wire `instructions` const so it points agents at the two capabilities Phases 5-7 actually shipped — the MCP resources surface and the Claude Code codegraph skill — and add the WIRE-03 guards that make every claim in it resolvable at test time.

Purpose: The current string says nothing about either capability. `internal/agents/instructions.go` has for three phases deferred "full tool guidance to the MCP initialize response" — a hand-off the initialize response never carried, which misdirected a real debug session on 2026-08-08. This plan is the half of the fix that lands on the wire; it also builds the guard mechanism that makes a future stale claim fail a test instead of shipping.

Output: A rewritten `instructions` const (≤600 bytes, single paragraph, all five anchors present) plus four new guard tests and two new checker helpers in `internal/mcp/instructions_contract_test.go`.
</objective>
