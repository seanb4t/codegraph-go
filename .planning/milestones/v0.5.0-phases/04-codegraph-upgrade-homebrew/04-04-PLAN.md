<objective>
Make every published description of `codegraph upgrade` under Homebrew match what plan
04-01 shipped, and record the two exit behaviours where a user and a script author will
each find them.

Purpose: `README.md` and `docs/RELEASE.md` currently tell readers, in the present tense,
that the self-updater does not detect a brew-managed install and that running it there has
undefined interaction with Homebrew's bookkeeping. Both statements become false the moment
04-01 lands. A published instruction that is wrong about a mutation path is worse than no
instruction. D-10 additionally requires the two exit behaviours on one command to be
documented rather than discovered.

Output: an amended cobra `Long`/`Example` for `upgrade`, an executing test pinning that
text, and corrected Homebrew-upgrade passages in `README.md` and `docs/RELEASE.md`.
</objective>
