    Create `internal/migrate/migratetest/fixture.go` (package `migratetest`). Provide `func BuildTSIndex(t testing.TB, v Variant) string` that: (1) locates the repo root by walking up from `runtime.Caller` until it finds `go.mod`, then reads `testdata/golden/ts-schema.sql` and `testdata/golden/ts-schema.dump.sql`; (2) opens a fresh read-WRITE DB at `t.TempDir()/ts-index.db` via `sql.Open("sqlite", dbPath)` (driver name literally "sqlite"; blank-import `_ "modernc.org/sqlite"`); (3) Execs the full DDL, then Execs the dump's INSERT rows with every `<EPOCH_MS>` token replaced by the fixed integer `1700000000000` (unistr('...') is left verbatim — SQLite evaluates it); (4) returns the `.db` path. `t.Cleanup` closes the DB. Define `type Variant int` and consts `VariantHappy`, `VariantAged`, `VariantDangling`:
    - VariantHappy: full DDL + full seed rows (exercises file:-source `contains` edges + unistr docstrings + nullable columns).
    - VariantAged: after the happy build, run `ALTER TABLE nodes DROP COLUMN return_type` and `ALTER TABLE edges DROP COLUMN provenance` (SQLite 3.35+ DROP COLUMN; modernc bundles 3.53) so the DB predates those later-added columns — proves D-09.4 defensive reads downstream.
    - VariantDangling: happy build + one extra `INSERT INTO edges(source,target,kind)` whose `target` is an id present in no `nodes` row (SQLite FK enforcement is off by default, so the insert succeeds) — the D-09.2 corruption fixture.
    Wrap every error `t.Fatalf("migratetest: <verb>: %v", err)`. Use only stdlib + modernc; no external process.
    Also create `internal/migrate/migratetest/fixture_test.go` with `TestBuildTSIndex_Variants` that builds each variant, opens it read-only, and asserts: happy has >0 nodes/edges/files and a `file:`-prefixed edge source exists; aged lacks the `return_type`/`provenance` columns (via PRAGMA table_info); dangling has exactly one edge whose target is absent from nodes.
  </action>
