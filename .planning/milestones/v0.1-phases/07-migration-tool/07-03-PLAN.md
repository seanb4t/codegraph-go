<objective>
Build the read half of the migrator: `reader.go` opens the TS SQLite DB read-only, detects it as a genuine TS source, guards the schema version, and streams rows from the allow-listed `files`/`nodes`/`edges` tables with defensive column enumeration and mandatory `rows.Err()` checks; `translate.go` maps each scanned row to `schema.Node`/`Edge`/`File` per the RESEARCH §Field Mapping tables (verbatim ids D-01, start_col/end_col CARRIED, ms→ns, metadata flatten, D-05 drops).

Purpose: MIGR-01's conversion core — the pure data transform of the SQLite bytes into proto records. This is where the fail-loud I/O discipline (RESEARCH Pitfall 2) and the D-05 start-column CARRIED correction land.

Output: `internal/migrate/reader.go` + `translate.go` with unit tests (pure translate helpers) and fixture-driven integration tests (defensive reads, detection, rows.Err).
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| untrusted SQLite file → migrate reader | An arbitrary user's aged/hostile `.codegraph/*.db` crosses into the process |
| DB contents → Pebble keys | `file_path`/`id` values from the DB become storage keys downstream |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-07-03-01 | Tampering / Denial of Service | A malicious or corrupt source SQLite file mutating the source or crashing the reader | high | mitigate | Open read-only (mode=ro + _pragma=query_only(1)) so no WAL/journal sidecar or write can touch the source (D-08); pure-Go modernc driver (no C memory-safety tail-risk); unreadable/locked file → loud open error, never silent. A read-only-byte-identity test asserts the source is unchanged. |
| T-07-03-02 | Injection | Table-name injection via PRAGMA table_info / SELECT | medium | mitigate | Table names are a fixed code-controlled allow-list ({files,nodes,edges}); DB-derived strings are never interpolated as identifiers. ScanTable rejects any non-allow-listed name before querying. |
| T-07-03-03 | Denial of Service | Malformed/huge edges.metadata JSON | medium | mitigate | metadata parsed with a bounded expectation (map of scalars); malformed → wrapped fail-loud error, not a swallow. |
| T-07-03-04 | Tampering | Crafted file_path/id forging a Pebble key into another namespace | low | mitigate | Downstream keys go through keys.go's length-prefixed appendSegment (existing T-01-02 mitigation); normalizeFilePath additionally strips absolute/backslash prefixes. Paths are keys only — the reader never opens files by file_path. |
</threat_model>
