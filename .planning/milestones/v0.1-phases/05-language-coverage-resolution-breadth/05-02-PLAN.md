<objective>
Generalize Pass 1 (discovery + extraction) to multi-language. Discovery becomes an extension→language-registry-driven generic walker with per-language project-descriptor hooks (Go's `go.mod` resolution is the first hook implementation) and a path-identity fallback for descriptor-less files. The extraction worker pool is fixed so each worker selects the correct parser + extractor per file's language (Pitfall 1) instead of owning one parser for its whole lifetime. The pipeline dispatches through the registry.

Purpose: This unblocks every per-language extractor plan (Wave 4) — without it, a single run over more than one language silently mis-parses.
Output: generalized `Discover`, a `DiscoveredFile.Language` field, the `ProjectDescriptor`/`ModuleKey` hook, and a per-worker language-keyed parser cache.
</objective>
