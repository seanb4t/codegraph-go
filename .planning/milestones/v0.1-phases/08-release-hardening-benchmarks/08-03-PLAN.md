<objective>
Build the deterministic, network-free synthetic-corpus generator that materializes a 100k+ file monorepo for the CI regression gate (PERF-02) and the bounded-memory / peak-RSS assertion (INDX-06). Test-first on the determinism property because "same seed → byte-identical output" is what makes a committed baseline meaningful — a non-deterministic corpus would flake the gate on every run (D-04).

Purpose: The CI regression gate must be fully reproducible and must never clone a remote repo. This generator is that reproducible substrate; the runner (Plan 08-07) indexes its output and compares against the committed baseline.
Output: `tools/bench/gencorpus` standalone tool with a proven determinism property.
</objective>

- `tools/bench/gencorpus/gen_test.go` (new) — determinism + file-count + cross-ref tests.
