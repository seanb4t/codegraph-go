<objective>
Implement **Pass 2 (sequential resolve)** of the two-pass pipeline (D-04): build a global symbol index over all Pass-1 results, resolve the unresolved references into `calls`/`imports`/`embeds` edges, collapse duplicate edges with a **deterministic** representative call-site, and write the whole graph through the single coordinated `GraphStore.Writer` in batched form (D-04a — never per-symbol commits).

This plan **ratifies the three RESEARCH open questions** (recorded as decisions here):
- **RQ-1 (imports edge target):** adopt RESEARCH recommendation (a) — a minimal **synthetic `package` pseudo-node** for **intra-module** imports only (id `package:<sha256-hex of import path>` via `nodeid.NodeID("package", importPath, importPath)`; `name` = last path segment, `qualified_name` = full import path). An intra-module import emits an `imports` edge file→package node. **External/stdlib imports produce no graph edge** (no in-repo node to target; D-03a forbids inventing edges beyond ground truth) — they may be retained on the intermediate for debugging but are not written.
- **RQ-2 (method-call resolution scope):** resolve only the **narrowest AST-local** receiver forms (still ground truth, not heuristic dispatch): a method calling another method on its own receiver, and a call through a freshly-constructed literal (`T{}`/`&T{}`/`new(T)`) whose type is lexically visible in the same/nearby scope, plus direct package-qualified selector calls. Anything requiring interface satisfaction, multi-hop embedded-field promotion, or return-value type inference stays an **unresolved ref** (never guessed, never silently dropped) — that is Phase-5 dispatch synthesis (D-06a).
- **RQ-3 (field nodes):** already ratified skipped in Plan 02-03 (not written).

Purpose: RES-01 cross-file resolution is the phase's headline capability; D-05 edge collapse + the deterministic tie-break is the determinism trap RESEARCH flags as the highest-risk correctness bug.

Output: `internal/indexer/symbolindex.go` (the index) and `internal/indexer/resolve.go` (resolution + dedup + single-writer commit).
</objective>
