<objective>
Ship the user-facing **CLI lifecycle** (INDX-01, INDX-02): the `codegraph` Cobra command tree with `init`, `index`, `uninit`, wired to `indexer.Run`, plus the `cmd/codegraph` binary entrypoint.

Command contract (D-01/D-01a/D-01b):
- **`init`** — create `.codegraph/` (Pebble store in a subdirectory, e.g. `.codegraph/store/`, executor's discretion per D-01b) **and** run a full from-scratch index in one step. On an already-initialized repo it **errors with guidance** ("already initialized — use `codegraph index --force` to rebuild"), never silently clobbering.
- **`index`** — deterministic from-scratch rebuild against an existing `.codegraph/`; `--force` rebuilds without prompting, `--quiet` suppresses progress, `--verbose` emits per-file/per-pass detail; default prints a concise end-of-run summary (files, nodes, edges, duration).
- **`uninit`** — remove `.codegraph/` cleanly; requires confirmation unless `--force`.

Purpose: this is the drop-in-swap surface a user actually types; it's the last mile that turns the two-pass engine into `codegraph init`. No new business logic — pure Cobra wiring over `indexer.Run` (glue, not TDD-core), plus integration tests over the real command surface.

Output: `internal/cli/{root,init,index,uninit}.go`, `cmd/codegraph/main.go`, and `go get github.com/spf13/cobra`.
</objective>
