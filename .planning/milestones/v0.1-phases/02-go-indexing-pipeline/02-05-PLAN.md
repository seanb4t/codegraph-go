<objective>
Wire the three seams into one orchestrated **from-scratch index** and prove it is **deterministic** — the phase's determinism contract (D-01a) that Phase 3's golden-diff and Phase 8's reproducibility gate both stand on.

`Indexer.Run(repoRoot, storeDir, opts)` does: `Discover` → Pass-1 `Extract` (bounded pool) → Pass-2 `Resolve` (single writer) → stamped `Meta`, opening the `GraphStore` once and closing it on every path (Close-once discipline, mirroring `pebble_store.Open`). It returns `Stats` (files, nodes, edges, unresolved, skipped, duration) for the CLI summary.

The determinism gate (INDX-02) indexes the fixture twice into separate temp stores and asserts `GraphStore.Export()` streams are byte-identical after normalizing the one genuinely volatile field, `Meta.last_sync_unix_ms` — diffing `Export()` output, NOT raw Pebble `.sst` files (LSM internals aren't byte-stable; RESEARCH §Pitfall 2). A companion structural fixture-diff proves RES-01/LANG-01 correctness on the multi-package fixture (the automated stand-in for success-criterion-4; the real-repo `weft-go` spot-check stays a documented manual verification per 02-VALIDATION.md).

Purpose: this is the seam the CLI drives; determinism here is non-negotiable and easy to break (map order, goroutine order, unsorted staging) — the gate makes a regression fail loudly.

Output: `internal/indexer/pipeline.go` (+ Stats/Options) and the determinism + structural tests.
</objective>
