  "only an explicit `--pretool-nudge=false` or uninstall removes it" needs Install to tell an explicit Off

  skill directory skips the manifest) would lose its hook on the next plain install. The zero value Keep
  also makes every existing caller (upgrade, the ownership table, all Claude tests) carry the recorded
  opt-in unchanged.

  manifest step is skipped, so an opt-in there is written but not recorded; Keep then neither refreshes nor
  removes it, and uninstall still removes it.
