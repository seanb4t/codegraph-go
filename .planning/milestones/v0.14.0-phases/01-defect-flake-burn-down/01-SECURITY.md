## Trust Boundaries

| Boundary | Description | Data Crossing |
|----------|-------------|---------------|
| third-party corpus source → indexer → SPA | guava's tree is untrusted third-party content; file/symbol names flow into cytoscape node labels and ids, and its geometry into the layout engine and renderer | untrusted identifiers and layout input |
| local browser → spawned `codegraph ui` HTTP server | check scripts and the maintainer drive a real Chromium against a loopback-bound server | loopback HTTP only; no external origin |
| browser → SPA under `default-src 'self'` | every asset (favicon included) must load same-origin; the CSP is not widened for cosmetic assets | static assets, no `data:` URIs, no `img-src` |
| the check script's allowlist → the meaning of "clean console" | an allowlist entry converts a fix into a waiver (D-07/D-08) | verdict semantics |
| supervising host process → daemon | the watchdog's parent-pid seam decides when the daemon exits | process identity |
| a live daemon/serve process holding the store → an independently-invoked `codegraph index --force` | a held lock must be refused before `RemoveAll`; a corrupt store warns and rebuilds | store lock state |
| an outstanding client page token → the coverage generation stamped after a rebuild | generation counter must survive every wipe path | pagination cursors |
| committed baseline JSON → `CheckRegression` | baseline/current corpus identity must match; reblessing is prohibited | perf-gate inputs |
| a recorded decision → future readers of the perf gate | GH #20's follow-ups end in a recorded decision in `tools/bench/BASELINE.md` | provenance |
| a pushed temporary ref → the project's CI | the discriminator bench run used a temporary branch, deleted after use | CI triggers |
| fork PR author → `pull_request_target` job; the repository working tree → that job; `$GITHUB_OUTPUT` → consuming step | fork-controlled file paths must not terminate a heredoc; no checkout of fork code with write permissions | PR-controlled strings |
| externally-generated asset → committed repository content | the brand mark is generated by a third-party model; shipped SVGs carry no metadata/C2PA payload | SVG bytes |
| vendored dependency internals → this repository's code | no `pnpm patch`, no `patches/`, no cytoscape/ELK version bump (D-06) | dependency surface |
| test binary → production code | the `getppid`/ticker seams are per-instance and unexported; no package-level test hooks | test seams |
