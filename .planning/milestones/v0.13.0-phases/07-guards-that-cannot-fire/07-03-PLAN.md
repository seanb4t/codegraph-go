<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| committed `.goreleaser.yaml` → generated signtest config | A developer-editable release config crosses into a generated copy that a real signing pipeline consumes; a drift here changes what is rehearsed versus what ships |
| script argv → the file it inspects | Caller-supplied paths determine which file the count check runs against; the wrong path makes every assertion true of a file nobody cares about |
| generated config → cosign subprocess | A config lacking the injected key silently redirects cosign to the keyless OIDC flow the calling job is denied |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-07-10 | Tampering | additions-only diff guard passing on an empty diff | high | mitigate | Count the added key lines and refuse any count other than exactly 1, printing the count; an unmatched anchor now reports zero and exits non-zero instead of reporting success |
| T-07-11 | Spoofing | the count check running against the wrong file | high | mitigate | Strict three-argument arity with a usage message and exit 2, plus a readability check on the input config naming the path it could not read |
| T-07-12 | Tampering | a duplicated sign-blob block injecting two keys | medium | mitigate | The same count assertion refuses two or more, with a message naming that failure mode separately from the zero case |
| T-07-13 | Denial of service | cosign falling through to the denied keyless OIDC flow and hanging | high | mitigate | This is the downstream consequence the count assertion prevents; the script refuses before goreleaser is ever invoked, and the script header records the causal chain |
| T-07-14 | Tampering | the RED demonstration editing the committed release config | high | mitigate | The perturbation is applied to a copy in a temporary directory; `git diff --quiet -- .goreleaser.yaml` is asserted before and after and recorded in the log entry |
| T-07-SC | Tampering | npm/pip/cargo installs | high | mitigate | No package-manager install occurs. The script adds no dependency; `shellcheck` and `task` are pre-existing developer tooling, not new supply-chain inputs |
</threat_model>
