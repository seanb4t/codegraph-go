## Tech debt

None of these blocks the milestone. Most were already deferred by the maintainer's short-path decision (2026-10-17) and are tracked as todos.

### Needs attention soon

- **The HOME-leak test is breaking a live tool now.** `TestUpgradeCommand_NoArgsDefaultsToLatest` (`internal/cli/upgrade_test.go:71`) does not stub `refreshInstalledSkillsFunc` or isolate `HOME`. As a result, every `go test ./internal/cli` rewrites the real `~/.claude.json` codegraph MCP command and the skill manifest. At this audit's session start, the codegraph MCP server failed with `ENOENT` on a deleted `go-build…/cli.test` binary. To repair the install today, run `codegraph install --target claude --location global` from the real binary. To fix the cause, stub the seam or set `HOME` to a temp dir in the test.
- **Flaky `TestColorFlagInvalidValue`.** It compares two `status` outputs byte-for-byte, and the `DB Size:` value can differ, so it failed twice this milestone. The fix is to mask that value with `plain_golden_test.go`'s `dbSizeRegexp`.
