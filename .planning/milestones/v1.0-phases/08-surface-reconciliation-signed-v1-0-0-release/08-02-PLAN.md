<objective>
Add a directory-path prefix filter to `files` as a NEW `--dir <prefix>` flag (SURF-02, CONTEXT D-03), retaining the existing language `--filter` untouched, and add the `-j` short alias for `--json` (SURF-03). The `--dir` matching semantics are a plain `strings.HasPrefix` check on the file path (or `./`+prefix), verified from TS 1.3.1's `bin/codegraph.js:1348-1354` — NOT a glob despite the `<dir>` placeholder text.

Purpose: Deliver TS's directory filter without breaking the Go-only language filter — the locked "keep ours + add TS's" divergence.
Output: `FilesOptions.Dir` field + prefix filter in the engine, `--dir`/`-j` on the CLI, recorded as a documented divergence for the SURF-05 audit.
