<objective>
Replace install's plain numbered-line prompt with a bubbles checkbox multi-select (and give uninstall the same), plus a `-y`/`--yes` non-interactive flag on both (TUI-03), keeping every off-TTY/`-y` path non-blocking (TUI-04).

Purpose: Per D-14 the bubbles multi-select (a custom checkbox `list.ItemDelegate` — bubbles has no built-in multi-select) pre-checks `agents.DetectAll(loc)`-installed targets and feeds the SAME `selectByIndices`/`ResolveTargetFlag`/`printAgentResults` resolution+reporting pipeline; only the input mechanism changes. Per D-15 `-y`/`--yes` (matching TS) is checked FIRST in the switch so it always resolves to `auto` regardless of TTY state (Pitfall 6). Per D-13 the off-TTY path stays the existing `auto` fallback. The picker Model lives in `internal/cli/tui` (D-09) so `internal/agents` stays charm-free.

Output: `internal/cli/tui/agentpicker.go` + tests; `-y` flag and picker wiring in install.go/uninstall.go.
</objective>
