<objective>
Add graceful daemon-stop signaling and the target-resolution orchestration the `daemon stop`/`stop --all` command (07-07) and the picker (07-07) both call (DMON-02).

Purpose: `sendStop` is a platform-split (POSIX SIGTERM / Windows hard-kill) primitive over the exact `os.FindProcess`+`Signal` call shape `lock.go`'s `isProcessLive` already uses. `StopMatching`/`StopAll` resolve targets from the self-healing registry (07-02), re-corroborate each via `isStale` before signaling (the safety invariant that a poisoned/forged/reused-pid record can never make codegraph SIGTERM an unrelated process — RESEARCH Security Domain), and are clean no-ops when nothing matches. Windows has no cross-process SIGTERM, so its stop is a documented hard-kill accepted for v1.0 (registry self-heals the ungraceful exit — Open Q#1, Assumption A4).

Output: `internal/daemon/stop.go` + platform files + tests. Charm-free.
</objective>
