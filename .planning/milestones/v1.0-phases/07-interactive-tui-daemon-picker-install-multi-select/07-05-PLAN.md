<objective>
Wire the registry (07-02) and watchdog (07-03) into `daemon.Run` so every explicitly-started daemon registers itself, is torn down when its parent dies, and deregisters on shutdown (DMON-02/03/04).

Purpose: Per D-06 Run registers its Record after `acquire()` and Deregisters via `defer` in the exact "remove, IsNotExist is nil" shape as the lockfile `release()`. Per D-07/D-08 Run starts `startWatchdog` (which cancels ctx on parent death) and joins its `stop()` on EVERY teardown path — the ctx-cancel path and the `ErrWatcherClosed` abnormal path — reusing the existing clean shutdown (no new teardown path). This is the single integration point both `daemon start` (07-07) and `serve --mcp`'s in-process watcher inherit, so wiring it here (not per-caller) gives both DMON-03 coverage.

Output: modified `internal/daemon/daemon.go` + new tests. Still charm-free; goleak gate stays green.
</objective>
