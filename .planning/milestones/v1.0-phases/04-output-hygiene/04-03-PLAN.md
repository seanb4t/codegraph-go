<objective>
Prove HYG-02 end-to-end and confirm HYG-01's effect on a real command, both through the
Phase-3 subprocess harness driving the real binary. Add (a) a raw-stdio frame-purity test
asserting every byte a real `serve --mcp` writes to stdout is a valid JSON-RPC frame
(D-06a), and (b) a CLI-noise-absence test asserting a real `sync` produces no Pebble-shaped
noise on stderr (D-09).

Purpose: The obvious frame-purity test built on the existing `newServeClient`/mcp-go client
can NEVER fail — mcp-go@v0.56.0's stdio transport silently `continue`s past any stdout line
that fails json.Unmarshal (RESEARCH Pitfall 1). This plan builds the narrow raw-stdio reader
that actually validates every line, and pairs it with the HYG-01 behavioral check on a
driven command. Two-way provability (structural guard in 04-02 + this end-to-end harness)
is the belt-and-braces standard Phase 3 established (D-06).

Output: `test/integration/mcp_stdout_purity_test.go` (D-06a) and
`test/integration/sync_noise_test.go` (D-09).
</objective>
