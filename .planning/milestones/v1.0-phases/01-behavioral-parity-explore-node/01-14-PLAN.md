Port the gate, sort, and central-file heuristics — H17, H18, H19 (RESEARCH §C.2/§4) — the final selection+ordering stage of the explore pipeline. H17 is EXPL-03's core: the file-relevance gate that stops weakly-connected Test* funcs from topping results. Heuristics (constants VERBATIM):
- H17 Relevance GATE (EXPL-03): keep a file if `fileGraphScore >= maxGraph*0.06` OR central OR entry/named-file OR change-surface-rescued OR `distinctTermHits >= 2`; only applied when `maxGraph > 0`; NEVER prunes below 2 files.
- H18 5-tier file sort: (1) named-seed file, (2) corroborated = entry/central + >=2 terms, (3) graph mass with 1%-of-max epsilon, (4) term hits, (5) !low-value, then !generated, then score, then node count.
- H19 Central-file selection: the 1-2 files with highest graph mass AND >=1 term hit (they earn the larger whole-file render ceiling).

Consumes the per-file scores + flags from plan 13 (scoring) and the shared isTestFile (plan 07) + isGeneratedFile (plan 04). Wave 4 (after scoring). Pure functions over the file-candidate set — TDD against synthetic file sets.
