## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| `.codegraph/store/` on-disk contents → `dbSizeBytes` walk | A repo-local directory whose entry count/permissions we do not control is traversed |
| `StatusResult` → `--json` / MCP output | Index metadata crosses to a caller that may be an AI agent processing attacker-influenced content |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-02-06 | Denial of Service | `dbSizeBytes` `filepath.WalkDir` | low | accept | The walk is confined to `.codegraph/store/`, a Pebble-managed directory with a bounded, small file count (SSTables + WAL + MANIFEST + OPTIONS) — not user-authored tree depth. `newestSourceMtime` already walks the far larger source tree on every `status` call, so this adds no new order of cost. |
| T-02-07 | Denial of Service | unreadable/racing store entries during walk | medium | mitigate | Per-entry errors return nil to skip rather than aborting (D-07 best-effort), and a failed walk leaves `DbSizeBytes` at 0 without erroring `Status()`. Asserted by the nonexistent-store-dir test in Task 1. A live Pebble compaction deleting an SSTable mid-walk is a normal, expected error and is absorbed by the same path. |
| T-02-08 | Information Disclosure | `filesByLanguage` counts in MCP output | low | accept | Language file counts are strictly less revealing than the `languages` list and `fileCount` already emitted today, and the map is json-excluded so it reaches only rendered output. No host paths are introduced by this plan — `ProjectPath`/`IndexPath` stay empty strings. |
| T-02-09 | Tampering | golden parity oracle weakened by the D-08 exemption | medium | mitigate | The exemption is applied at ONE call site with an explicit `except` argument naming exactly one key, and is immediately replaced by three narrower assertions (present, integer, `> 0`, plus MB-shape). The shared `volatileKeys` map that guards the frozen TS fixtures is asserted untouched via `git diff testdata/golden/golden_test.go` being empty. |
| T-02-SC | Tampering | npm/pip/cargo installs | high | mitigate | Not applicable — zero new dependencies (stdlib `io/fs`, `path/filepath` only, both already imported by this file). `go.mod`/`go.sum` must be unchanged by this plan. |
</threat_model>
