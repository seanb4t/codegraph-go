<objective>
Wire the MCP surface: swap six `tools.go` call sites from JSON to markdown
(SURF-06 + D-17), construct one server-scoped `CachingDetector` and close it
over every handler (D-13), and prefix the compact worktree notice on all 7
non-status read tools (WORK-02, D-12).

★ THIS PLAN CARRIES THE PHASE'S BIGGEST DELIVERY RISK — read before starting.

**ZERO existing tests assert the MCP success payload of ANY of the 5 SURF-06
tools.** MCP coverage today is `explore` (markdown) + `status` (**error path
only**). `callers`/`callees`/`impact`/`search`/`files` have no MCP-surface
assertion of any kind. SURF-06 could be skipped wholesale and `go test ./...`
stays fully green. That is a literal recurrence of Phase 1's CR-02:
"implemented + unit-tested + marked complete ≠ DELIVERED."

The red test in Task 1 is therefore MANDATORY and must assert BOTH that the
text is not valid JSON AND that it contains a markdown marker. Either assertion
alone is defeatable: the negative makes a silent regression to `json.Marshal`
impossible; the positive makes an empty or garbage render impossible.

The risk is inverted from intuition. The feared hazard — mutating a shared
`Marshal*JSON` helper and breaking the CLI — is LOUD: 7 tests across 3 files
catch it instantly. The genuinely silent failure is the MCP side going
unverified in either direction.

Purpose: make SURF-06 and WORK-02 reachable through the real MCP tools, not
merely implemented in `internal/query`.
Output: markdown on all 8 MCP read tools, a server-scoped detection cache, and
the notice on 7 of them.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| MCP client `path` argument → `openEngine` → `Engine.startPath` → git subprocess | An AI-agent client, which may be processing attacker-influenced content, supplies a directory |
| MCP tool result text → the consuming language model | Rendered markdown containing repo content and host paths crosses to the agent |
| MCP server process stdout | Reserved exclusively for the JSON-RPC transport framing |
