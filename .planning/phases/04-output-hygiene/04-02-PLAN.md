<objective>
Add a build-time structural guard that makes any stdout write from a serve-reachable
package a build failure, locking in HYG-02's "no library log output ever reaches MCP
stdout" guarantee against future regressions. A go/packages + go/ast + go/types archtest
mirrors the two existing precedents (`import_graph_test.go`,
`modernc_confinement_test.go`) and fails if any of six named packages references
`os.Stdout`, calls a bare `fmt.Print*`, or calls `log.SetOutput`.

Purpose: HYG-02 is a guarantee-and-regression-lock, not a behavior change — scouting
found zero stdout writers in the guarded packages today (the only `os.Stdout` match is a
comment, D-07). This makes that invariant permanent and machine-checked.

Output: `internal/graphstore/archtest/stdout_confinement_test.go` (the guard) and
`internal/graphstore/archtest/stdout_detection_selftest_test.go` (mutation-proof of the
detection logic).
</objective>
