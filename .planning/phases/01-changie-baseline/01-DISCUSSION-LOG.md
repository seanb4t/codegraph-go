## History placement

| Option | Description | Selected |
|--------|-------------|----------|
| One verbatim `.changes/vX.Y.Z.md` per existing release block | Fourteen seed files byte-sliced from CHANGELOG.md; `changie merge` emits header + all version files, so history survives | ✓ |

## Proof harness placement

| Option | Description | Selected |
|--------|-------------|----------|
| Go test for config shape + `check:changie` Taskfile drift target for live-tool behaviour, wired into ci.yml | Static assertions get TDD RED evidence; live checks follow `docs:cli:drift` shape and are covered by existing workflow-body guards | ✓ |
| Everything in one Go test that execs changie | Needs the binary built inside the test; slower, mixes shape and behaviour | |
| Everything in a Taskfile target | No RED-first test for the config shape; harder to assert set equality of seeds vs headings | |

**Choice:** split (recommended default)
**Notes:** Refusal cases must assert on changie's stderr text, not exit status alone (rule `84d1gfpywd`).
