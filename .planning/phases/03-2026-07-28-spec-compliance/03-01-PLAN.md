<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| MCP client → stdio JSON-RPC → `internal/mcp` middleware | Untrusted, possibly agent-relayed, possibly attacker-influenced request bytes cross here. go-sdk owns framing and `_meta` validation upstream of any codegraph-go code (03-RESEARCH Q1, PROVEN-ABSENT). |
| `internal/mcp` middleware → `mcp.DiscoverResult` fields | Server-authored response data crossing back out to the client. Anything written here is client-visible on every discover. |
| Wire-oracle capture → frozen `.golden` file in the repository | Captured subprocess output becomes a committed artifact. Host-specific bytes reaching a golden would leak the capturing machine's paths into the repo. |

No client-supplied value reaches it. Enforced by the acceptance criterion that `TTLMs` is never assigned and no protocol-version literal appears in the middleware's executable body. |
