<objective>
Add the charm-free global daemon registry that lets the picker (07-07) and `daemon stop --all` (07-04) list daemons across projects, self-healing stale records on read.

Purpose: DMON-04. Per D-04 the registry is a directory of one atomic record file per running daemon at `~/.codegraph/daemons/` (never a single shared JSON file — avoids a global write-lock). Per D-05 it self-heals on every read by reusing `lock.go`'s existing `isStale`/`isProcessLive` (same package) — the exact "detect+clear stale on every independent call" discipline `acquire()` already uses, generalized from one lockfile to many record files. Per D-06 register/deregister mirror the lockfile's `release()` shape (07-05 wires them into `daemon.Run`).

Output: `internal/daemon/registry.go` + tests. Charm-free (the archtest already guards `internal/daemon`).
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| filesystem → process | On-disk record files are parsed and their pids may later be signaled (07-04) |
| concurrent daemons → registry dir | Multiple daemons write/prune the same directory without a global lock |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-07-02-01 | Tampering | registry record file | high | mitigate | A record is never trusted for signaling on its own — List() requires the pid pass lock.go's isStale (live AND /proc start-time corroborates rec.StartedAt), the same PID-reuse mitigation the lockfile uses; a forged/stale pid is pruned, not acted on |
| T-07-02-02 | Input Validation | malformed record JSON | medium | mitigate | json.Unmarshal into a fixed Record struct; a decode failure is skipped as "unreadable", never propagated or evaluated as code |
| T-07-02-03 | Denial of Service | unbounded registry dir | low | accept | Directory is written only by `codegraph daemon start` under the same user account — not an externally-reachable or multi-tenant surface (RESEARCH Security Domain) |
| T-07-02-04 | Access Control | ~/.codegraph/daemons/ perms | low | mitigate | Per-user home directory, standard fsatomic file modes — same trust boundary as the existing .codegraph/daemon.lock |
</threat_model>
