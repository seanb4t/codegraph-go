## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Documentation -> contributor behaviour | Prose that overstates a guarantee (automated dependency updates, a target that "just works") causes contributors to skip a real prerequisite |
| Guard allowlist -> enforced invariant | An exception list that can grow silently converts an enforced property into a decorative one |
| Scratch checkout -> working tree | A verification run that writes back into the repository contaminates the thing it is verifying |
