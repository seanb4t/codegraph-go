<objective>
Rewrite the marker-fenced `codegraphInstructionsBlock` that `codegraph install` injects into Claude, Codex, opencode and Gemini instruction files so it points at the same capabilities the rewritten wire `instructions` const does, names nothing that was not shipped for every one of its four targets, and carries a doc comment that describes what it actually does.

Purpose: This const's doc comment has for three phases claimed the block "defers full tool guidance to the MCP initialize response (Phase 3)" — a hand-off that was never built, and the origin incident of this whole milestone. Removing the stale claim without replacing it with a new unbacked one is the entire point: the block is shared across four targets, only one of which received a skill.

Output: A rewritten `codegraphInstructionsBlock` (fences untouched, one new reference-docs bullet), a corrected doc comment, and a derive-from-source honesty guard with its non-vacuity proof.
</objective>
