<objective>
Wire HOOK-03's fallback surfacing: a non-interactive plain-text port of TS offerWatchFallback into init's success path (D-07), and TS-parity best-effort hook cleanup into uninit after .codegraph/ removal (D-06). Both gated exactly as TS: init prints nothing when the watcher runs normally, and only points at `codegraph githooks install` (no auto-install) when the watcher is disabled in a git repo without hooks.

Purpose: Makes HOOK-03's "narrower trigger" real — hooks are surfaced as the watcher-disabled fallback, not an always-on feature — and keeps the `codegraph uninit` advice in the marker block truthful.
Output: the D-07 advisory in init.go, the D-06 cleanup in uninit.go, and mutation-proof reachability tests for both.
</objective>
