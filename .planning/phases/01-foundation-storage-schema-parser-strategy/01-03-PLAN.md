<objective>
Establish the narrow, backend-swappable `Parser` interface (D-05b) and its production CGo tree-sitter backend (Option A) for Go and Python — the two spike-partner languages (D-05: Go is LANG-01; Python carries a real external C scanner). The interface and CGo backend ship as production code; Plan 01-07 builds the wazero comparison arm and the benchmark on top of this interface. If CGo is selected by the spike, this backend is the single documented CGo exception feeding DIST-05.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| arbitrary source file → parser | The parser ingests arbitrary, potentially adversarial third-party source (Security Domain V5) |
| C scanner ↔ Go host | tree-sitter grammar external C scanners run in-process with no memory isolation from the Go host |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-03 | Denial of Service | Parse of pathological/oversized input | high | mitigate | `MaxSourceBytes` file-size ceiling enforced in `Parse` BEFORE bytes reach the C parser; `TestParserRejectsOversizeInput` proves it. Directly serves INDX-06 bounded-memory later. |
| T-01-01 | Denial of Service | C-level segfault in a grammar external scanner (Python INDENT/DEDENT scanner) | high | accept (measured, not eliminated here) | RESEARCH is explicit: a C segfault is NOT catchable by Go `recover()` — documented in the interface doc comment so no false safety net is designed in. The crash-isolation dimension is *measured* by Plan 01-07's spike against deliberately malformed input; a subprocess isolation boundary is a Phase 2+ option if the risk proves unacceptable. Accepting for Phase 1 with the ceiling as the partial control. |
| T-01-SC | Tampering | go-tree-sitter + grammar modules | low | accept | tree-sitter org-maintained, version-aligned v0.25.0, Approved in RESEARCH §"Package Legitimacy Audit" |
</threat_model>
