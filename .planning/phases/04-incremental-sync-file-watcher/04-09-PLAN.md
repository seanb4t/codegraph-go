<objective>
Prove SYNC-06: the long-running watcher/daemon is goroutine-leak-free, verified by soak tests
(ROADMAP success criterion 5, D-07). This is the acceptance evidence that the context-cancellation +
`sync.WaitGroup` lifecycle discipline built in Plans 04-05/04-07 actually holds under many
watch→debounce→sync cycles.

The subtle hazard (RESEARCH Pattern 7): `time.AfterFunc`'s callback runs in its own goroutine
outside the caller's context tree, so the debounce timer's callback must check `ctx.Err()` and the
shutdown path must call `timer.Stop()`; and the test MUST `wg.Wait()` for every shutting-down
goroutine before `goleak.VerifyNone` runs, or a still-joining goroutine is a false-positive leak.

Purpose: the last gate — turn the leak-freedom claim into a repeatable, CI-runnable assertion using
`go.uber.org/goleak` (named stack traces on failure).
Output: a watch soak test + `goleak.VerifyTestMain` guard and a daemon soak test, plus the
test-only goleak dependency.
</objective>
