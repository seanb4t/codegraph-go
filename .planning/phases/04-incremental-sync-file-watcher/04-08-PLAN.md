## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-04-08-01 | Tampering | serve in-process fallback vs daemon (two writers) | high | mitigate | The in-process watcher acquires the SAME .codegraph/daemon.lock a standalone daemon uses (Plan 04-07) — the lock makes them mutually exclusive, preserving the single-writer invariant (INDX-05) |
| T-04-08-02 | Tampering | unlock destructive op | high | mitigate | unlock delegates to daemon.Unlock (stale-only; refuses a live lock with ErrLockLive) — the CLI never force-removes the lockfile itself |
| T-04-08-03 | Elevation of Privilege | path resolution | low | accept | sync/daemon/unlock reuse the existing targetRoot/resolveStartPath + ErrNotInitialized guards (no new path-trust surface beyond the repo the user already targets) |
| T-04-08-SC | Tampering | dependencies | low | accept | Pure wiring over already-built engine packages; no new package-manager installs; no [ASSUMED]/[SUS] packages |
</threat_model>
