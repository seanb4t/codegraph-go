F3 (Java + C# slice of the priority-4 languages): emit the new Pass-1 edge kinds from the Java and C# extractors at their language-specific tree-sitter anchors, mirroring the Go reference implementation from plan 05. The Pass-2 resolution + extends/overrides synthesis is already shared in resolve.go (plan 05) — this plan only adds the per-language Pass-1 capture sites.

Anchors (RESEARCH §B table):
- instantiates: Java/C# `object_creation_expression` (`new T()`)
- references: Java/C# field/type reference not a call callee or import (de-dup vs calls)
- type_of: Java/C# field/local declared type
- returns: Java/C# method return type
