Planner notes:
- Mechanics chosen within D-08's discretion (CONTEXT "Claude's Discretion"): mtime, not a content
  timestamp; `O_NOFOLLOW` on the open PLUS an `Lstat` pre-check and an fstat on the open descriptor; the
  mtime is set through the descriptor (`syscall.Futimes`), never by a path-based call — a path-based time
  setter re-resolves the name and would reintroduce the swap race D-08 closes (RESEARCH Pattern 3). No
  truncation happens at all, so "never truncate someone else's file" holds by construction.
- The two symlink refusals are tested SEPARATELY (read layer and record layer) so each is individually
  proven able to fail — a single end-to-end symlink test would stay green under either mutation alone,
  because the other layer still refuses.
- Foreign ownership cannot be produced by a non-root test, so `cooldown.go` reads the uid through an
  unexported package var (`currentUID = os.Getuid`) that same-package tests override.
- darwin and linux are the only release GOOS (`.goreleaser.yaml`); `syscall.O_NOFOLLOW`, `syscall.Futimes`,
  `syscall.NsecToTimeval` and `syscall.Stat_t.Uid` exist on both (RESEARCH Environment Availability).

  the positive-control task. Sequential by design; GOTOOLCHAIN=go1.26.6 on every Go command; every hook
