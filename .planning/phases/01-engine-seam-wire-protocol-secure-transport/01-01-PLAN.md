<objective>
Stand up the phase's transport spine: an exact-match Origin/Host control, a protobuf
codegen pipeline, and a `codegraph ui` process that serves one real read-only RPC
end-to-end over a loopback listener.

Purpose: this is the phase's tracer. It proves the whole architecture — cobra command →
ephemeral loopback listener → rebinding guard → Connect handler → `internal/query.Engine`
→ typed response — on one path before any of it is built out. The ROADMAP's blocking
order is why the guard is Task 1 rather than part of the tracer: "no RPC handler may ship
before SRV-02's Origin/Host control exists", so the control is a committed, RED-proven
artifact before a handler exists to protect.

Output: a working `codegraph ui`, a generated `codegraph.ui.v1` wire surface, and a
guard whose rejection has been watched fail against a build without it.
</objective>
