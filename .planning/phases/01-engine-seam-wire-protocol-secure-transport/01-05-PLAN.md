<objective>
Extract the structured `ExploreResult` seam, give every reachable component type an
exported name, make `internal/query`'s errors classifiable without string matching, and
prove both extracted seams safe by watching the oracle fail against each.

Purpose: `Explore()` already computes the whole `groups`/`symbolCount`/`blasts`/`sources`/
`skeletonFiles` tuple before calling `RenderExplore`. Exposing it is the ENG-02 twin of
plan 01-04's ENG-01 work. Two things make it more than a mechanical repeat. First,
`Explore()` has five separate early returns that each hand back an already-rendered
zero-result string, and every one has to funnel into the structured type or the seam has a
hole. Second, the component types the result exposes are currently unexported, so a
consumer outside `internal/query` can read their field values but cannot name the types,
declare a mapper signature over them, or construct one in a test — which is the wrong shape
for a seam Phases 3 through 6 must consume.

The typed-error work lands here because plan 01-09's Connect error mapping has nothing to
map from otherwise: node-not-found is a bare `fmt.Errorf` today, and the RPC layer is
forbidden from matching on error strings. The constraint is that the message bytes cannot
change.

Output: `ExploreResult`, exported component types, exported error sentinels with unchanged
message bytes, and the recorded D-04 mutation-proof over both seams.
</objective>
