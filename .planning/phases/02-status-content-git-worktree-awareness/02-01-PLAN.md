## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| caller cwd / `--path` / MCP `path` arg → `gitmeta` | Attacker-influenceable directory strings become `cmd.Dir` for a `git` subprocess |
| `gitmeta` → local `git` binary | An arbitrary third-party repo's `.git` config/state is parsed by git on our behalf |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-02-01 | Tampering | `WorktreeRoot`/`CommonDir` argv | medium | mitigate | `exec.CommandContext(ctx, "git", "rev-parse", "--show-toplevel")` uses a fixed argv and passes the untrusted value only via `cmd.Dir`. No shell is invoked (`os/exec` execs the binary directly), so no metacharacter in the path can inject an argument or a command. Verified by the absence of any `sh -c`/`exec.Command("sh"...)` construction in this package. |
