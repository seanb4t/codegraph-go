## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| GoReleaser cask render -> a user's machine | `hooks.post.install` is Ruby that runs on the user's machine at `brew install` time with their privileges. It is the only mechanism that can fail an install before the user hits a broken binary. |
| prior install residue -> current install's gate | A previous failed install leaves files in the shared man directory that the current install's assertion can read. |
