<objective>
Wire the thinnest production-quality path from the FileGraph rpc to a rendered,
hierarchically laid-out, directory-grouped graph on `/graph` — and build it as the
instrument GRF-01's measurement will run against.

This is the phase's tracer and its highest architectural risk sits here. Three new
runtime dependencies enter the committed bundle and therefore the signed binary;
cytoscape's compound-node model is unlike anything in this codebase; elk's layered
algorithm has documented rough edges on cross-hierarchy edges; and the whole stack
has to stay interactive at 3,233 nodes and 21,554 edges. If that composition does
not work, it must surface after one commit, not after cycle styling and in-place
expansion are already built on top of it.

Scope discipline, stated plainly. This plan builds the minimum renderer path GRF-01
must measure: file nodes, directory compound parents, aggregated edges, a layered
layout, and a real failure state. It deliberately stops before cycle styling
(05-05), per-kind count affordances (05-05) and in-place expansion (05-06), all of
which are gated on 05-04's recorded verdict. Measuring a view that is not the one a
developer sees would make the measurement worthless, which is why the directory
compounds and the layered layout ARE in the tracer rather than deferred.

`/graph` exists today as a Phase-2 placeholder whose body renders internal planning
vocabulary. Per D-18 this plan FILLS that route and restructures no navigation, and
it replaces that copy with real user-facing text.

Purpose: prove the renderer composition end to end, and give 05-04 something real to
measure.
Output: three approved dependencies, the GRF-05 seam component, a DOM-free transform
module, a working `/graph`, and a rebuilt committed bundle.
</objective>
