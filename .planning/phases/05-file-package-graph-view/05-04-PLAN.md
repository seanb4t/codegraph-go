<objective>
Resolve GRF-01. Measure the shipped graph view against the pass condition locked in
05-01, record the result as a committed artifact next to this project's existing
recorded-measurement artifacts, and let that record — not a preference — decide
whether the phase's remaining work proceeds.

This is the blocking within-phase gate the ROADMAP names. Everything before it built
the instrument; nothing after it runs until this plan writes a verdict. D-02 is
explicit that a failure here must be reachable and actionable rather than treated as
impossible, so the failure path is not a footnote: a missed bar halts the phase and
escalates with the two remedies the threshold artifact already committed to, and
adjusting the threshold is not among them.

The comparison itself is committed code rather than a judgement call, and it fails
closed. A metric that is absent, non-numeric, or unreadable is a FAIL — because the
single most likely way this gate produces a wrong answer is a measurement that
quietly did not happen being read as a measurement that quietly passed.

Two mechanisms make that more than a claim, and both are this revision's answer to
the cross-AI review's principal finding. First, `web/scripts/graph-measure.mjs`
OWNS the browser session and writes the raw observation from a `finally` block, so
a session that dies at launch, at navigation, while polling the seam, or mid-sample
still leaves a reason-bearing artifact behind; there is no path where the browser
takes the record down with it. Second, a FAIL is a SUCCESSFUL outcome of this plan's
verification: the verify command accepts a well-formed FAIL and rejects only an
artifact that is missing, self-contradictory, or judged against the wrong corpus.
A gate that could not durably record its own worst case would be a gate in name only.

Purpose: turn the phase's blocking gate from an intention into a record.
Output: a fail-closed verdict script and an always-records measurement wrapper, both
with tests, and `corpora/graph-render-observations.json` carrying every measured
value beside the bar it was judged against — including when the measurement failed.
</objective>
