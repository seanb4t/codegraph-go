<objective>
Deliver GRF-03 the way D-04 chose it: clicking a file expands it into its symbols
inside the same picture, using the renderer's compound-node support, rather than
navigating away or opening a panel beside the graph.

This is the decision that drove the whole renderer narrowing. D-02 recorded openly
that native compound nodes are a locked prerequisite because D-04 wanted in-place
expansion, and that this narrowed the field to Cytoscape before any measurement. This
plan is where that prerequisite is spent. If expansion works, the narrowing was
bought and paid for; the deep-link and side-panel alternatives stay deferred, and
must not be quietly reached for the moment expansion turns out to be fiddly.

The expansion has to be honest about three things a naive implementation gets wrong:
a second click must not re-fetch and must not duplicate children; collapsing one file
must not disturb another expanded file; and a symbol list the server capped must say
it was capped, because a partial list presented as complete is worse than no list.

Purpose: the last requirement in the phase, and the one the renderer choice was made
for.
Output: tap-to-expand and collapse inside the seam, a truthful truncation notice, a
named failure state, and a rebuilt committed bundle.
</objective>
