<objective>
Cut a real, permanent release through the now-proven pipeline, and verify it the way an existing user would.

Purpose: REL-02 has two halves and both are closed here — releases are cut by release-please from Conventional Commits with no human running `git tag`, and the resulting signed artifacts still satisfy the cosign identity that every already-shipped binary hard-codes. The version is whatever release-please computes; this plan publishes it, it does not choose it.
Output: a published, signed, SBOM'd, provenanced release, and recorded evidence that a real `v0.1.0` binary upgrades to it.

## Artifacts this plan produces
None in the repository — the artifact is the published release. The durable record is the SUMMARY's captured command outputs.
