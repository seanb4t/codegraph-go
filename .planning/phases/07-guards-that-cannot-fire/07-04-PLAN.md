<objective>
Give `post-release-verify.yml`'s event-aware conclusion guard a test that fails when the guard is removed or inverted on any single job (GRD-04, todo T-02-18), delete the tautological tap App secret-distinctness test rather than rewriting it (D-09), and close the mutation log with its fourth family plus the deletion record (GRD-06).

Purpose: the disjunct on each job's `if:` is what keeps a `workflow_run`-triggered verification from running against a release that failed. It is load-bearing, it is repeated five times by hand, and nothing checks it. A test that compared constants it wrote itself would be the same class of guard this phase exists to eliminate — so this one parses the real file and asserts a verbatim string against every job the document actually declares.
Output: the new field, const and two test functions; one deleted test; family (d) and the GRD-05 record in the mutation log; two todos closed.
</objective>
