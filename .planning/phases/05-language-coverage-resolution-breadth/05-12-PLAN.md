<objective>
Deliver framework-aware routing (LANG-07): a per-framework detector registry keyed by (language, framework) that emits `route` kind nodes linked to their handler symbols (D-08). Detection is AST-based (Pattern 4 — not the parity target's regex, avoiding ReDoS) and opt-in per detected framework dependency/import signature (D-09). Route→handler edges use the existing `"calls"` edge kind with `Provenance="heuristic"` so the existing RefKindCalls reverse-adjacency traversal picks them up with zero query-engine changes.

Purpose: The five priority-framework families — Gin, Spring, ASP.NET, Django/Flask/FastAPI, Express/NestJS — get their routes surfaced.
Output: `routes/` detector registry + five detectors + pipeline wiring.
</objective>
