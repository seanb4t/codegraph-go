Synthesize interface→implementation dispatch edges with provenance (RES-02, RES-03) and make callers/impact traverse dynamic dispatch at query time. Go uses bounded structural method-set matching; Java/C# use declared-`implements` promotion (Pattern 2) plus a two-pass conformance retry so inherited-method calls resolve (Pitfall 3). Callers/Impact gain an `implements`-edge traversal step.

Purpose: The dynamic-dispatch requirement — a call through an interface reaches every concrete implementation.
Output: `dispatch/implements.go`, resolve-time synthesis + conformance retry, and query-time implements traversal.
</objective>
