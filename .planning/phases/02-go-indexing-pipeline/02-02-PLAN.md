<objective>
Build the deterministic **file-discovery seam** (Pass-0 of the pipeline) and the **shared test fixture** every downstream extraction/resolution/determinism test binds to.

Discovery walks the repo with `filepath.WalkDir`, skips `vendor/` and any dot-prefixed directory (`.git`, `.codegraph`), and for each `*.go` candidate calls `go/build.Context.MatchFile(dir, name)` — the exact primitive the Go toolchain uses — to decide inclusion (no `go list` subprocess, works on a repo with compile errors). It computes the repo's base module path once via `golang.org/x/mod/modfile` and tags each file with its full import path (`modulePath + "/" + relDir`), which Pass 2 needs for cross-package resolution.

Purpose: LANG-01 indexing starts by enumerating the right files in a stable order; import-path tagging is the substrate RES-01 resolution builds its symbol index on. The fixture is the Wave-0 dependency the whole phase's tests require.

Output: `internal/indexer/discover.go` (+ `DiscoveredFile` type consumed by Pass 1/2); a nested `internal/indexer/testdata/gofixture/` module (excluded from the parent build because it lives under `testdata/`).
</objective>

type DiscoveredFile struct {
    AbsPath    string  // absolute path on disk, for reading bytes
    RelPath    string  // slash-normalized path relative to repo root, the file_path stored on Node/File
    ImportPath string  // module path + "/" + relDir; "" relDir means the module root package
}

// Discover(root) walks root, returns DiscoveredFiles sorted by RelPath (stable, ASCII byte order),
// plus the resolved module path. Skips vendor/ and dot-prefixed dirs; includes a *.go file iff
// build.Default.MatchFile(filepath.Dir(abs), filepath.Base(abs)) is true.

Key stdlib/dep facts (RESEARCH §Pattern 1, §Pitfall 5):
- build.Default.MatchFile(dir, name) — pass the file's OWN parent dir, never a hoisted root.
- modfile.Parse("go.mod", data, nil).Module.Mod.Path — the base import path.
