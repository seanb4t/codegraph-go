```text

Entries (file, or stdin when --entries is absent): one per line, "<Kind><TAB><Body>"; blank lines ignored.

     CHANGIE_FRAGMENTS_GH gh executable (default: gh)
Always exported to children: CI=true (changie), GH_PROMPT_DISABLED=1 (gh).

stdout on --list success, in this order:
  changie-fragments: phase <padded> <phase_dir>
  changie-fragments: range <base>..HEAD
  changie-fragments: kinds <K1>,<K2>,...
  changie-fragments: pr <n>
  changie-fragments: pending <plan-id> <summary-path>   (one line per pending SUMMARY, ascending)
stdout on --write success (last line):
  changie-fragments: wrote <count> fragment(s) in <short-sha>: <path> [<path>...]
skip (stdout, exit 0, nothing written, no commit):
  changie-fragments: skip: <reason-id>: <detail>
  reason-ids: gsd-tools-missing disabled changie-unavailable no-changie-config phase-not-found
              no-summaries locked already-recorded gh-missing pr-lookup-failed no-open-pr
              no-user-visible-change
error (stderr):
  changie-fragments: error: <error-id>: <detail>
  exit 2, before any write: usage bad-pr malformed-entry undeclared-kind
  exit 1, after a write began (own fragments deleted, lock released, no commit): changie-failed commit-failed

Preflight order (--list skips the lock and the entries steps):
  args -> repo root (--repo, else git rev-parse --show-toplevel) -> gsd-tools launcher -> disabled
  -> changie-unavailable -> no-changie-config -> phase-not-found -> no-summaries -> [--write: lock]
  -> already-recorded -> [--write: entries: malformed-entry/undeclared-kind exit 2, zero -> no-user-visible-change]
  -> PR (explicit --pr; else gh-missing / pr-lookup-failed / no-open-pr)

Config reads:  <gsd> query config-get workflow.changie_fragments --default true --raw
               <gsd> query config-get workflow.changie_command --default changie --raw
Phase dir:     <gsd> query init.phase-op <N> --pick phase_dir   (empty output -> phase-not-found)
               <gsd> query init.phase-op <N> --pick padded_phase
PR lookup:     <gh> pr list --head <current-branch> --state open --json number --jq '.[0].number // empty'
Base ref:      --base, else `git rev-parse --abbrev-ref origin/HEAD`, else main, else master, else the whole HEAD history
Covered set:   Changie-Summaries values of commits in <base>..HEAD whose Changie-Phase equals N (leading zeros ignored)
Lock:          mkdir "<absolute git-dir>/changie-fragments.lock"; held -> skip locked; always removed on exit
Fragment commit: git add -- <written files>; git commit -F <message file>, message =
  docs(<padded>): add changelog fragments
  (blank line)
  Changie-Phase: <N, leading zeros stripped>
  Changie-Summaries: <plan ids ascending, comma-separated, no spaces>
```
