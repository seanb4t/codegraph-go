## The measurement rule this phase learned the hard way

Both flagship censuses (05-04, 05-05) used **line-based** `rg`. A phrase wrapped across a Go comment line break —

    // ...rationale (no TS
    // precedent for this CLI placement).

— returns ZERO for `rg 'no TS precedent'`. That is why 10 locations survived a green sweep, and why all three of `behavioral_test.go`'s originally-reported misses are wrapped. Every census in this plan therefore:

- uses `rg -U` (multiline);
- counts with `rg -o | wc -l`, never `rg -c` (which counts matching LINES per file);
- word-bounds every bare term (an unbounded `ports` already matched inside `reports` this phase and caused an executor to reword innocent prose);
- carries a **positive control** — the instrument must be shown to find a known-positive before any zero it reports is believed (repo rule `84d1gfpywd`: a guard must carry a positive assertion that it did its work);
- asserts the number of files it actually scanned, so a wrong working directory or a too-broad exclusion cannot manufacture a zero.
