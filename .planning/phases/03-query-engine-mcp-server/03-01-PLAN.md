<objective>
Additively extend the `graphstore.Reader` interface with node and file enumeration (D-03). The current `Reader` (`GetNode`/`GetFile`/`GetMeta`/`IterateEdges`) has no way to list nodes or files, which `query`, `search`, `files`, `status.nodesByKind`, and `status.languages` all require. This plan adds `IterateNodes()` and `IterateFiles()` as contiguous range scans over the existing `n/` and `f/` namespaces, mirroring `IterateEdges` exactly.

Purpose: This is the read-path spine of the whole phase — no query command can be built until the store can enumerate. It is deliberately additive-to-the-interface-only: no key change, no schema bump, no reindex, and `archtest` is unaffected (D-02/D-03).
Output: Two new `Reader` methods + their iterator types + pebble implementations, behavior-tested against a seeded store.
</objective>
