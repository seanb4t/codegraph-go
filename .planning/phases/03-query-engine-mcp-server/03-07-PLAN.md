<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| MCP client → tool handlers | A malicious/compromised MCP client can pass malformed `query`/`path`/`limit`/`depth` tool args over stdio |
| CODEGRAPH_MCP_TOOLS env → registration | Operator-controlled allowlist; unknown/garbage names must not crash startup |
| stdout | Reserved for JSON-RPC framing — diagnostics must go to stderr |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03-07-Inj | Tampering | tool arg parsing | high | mitigate | Apply the SAME validate/clamp bounds as the CLI (D-08b) via mcp-go typed `Required()`/`WithString`/`WithNumber` schemas — MCP handlers must not validate more loosely than CLI flags |
| T-03-07-DoS | Denial of Service | depth/limit/max_files args | high | mitigate | Reuse `clampDepth`/`validateLimit`/`validateMaxFiles` inside each handler before traversal |
| T-03-07-Leak | Information Disclosure | error/log destination | medium | mitigate | Send unknown-allowlist warnings and errors to stderr, never stdout; normalize absolute-path values in any error reaching the client |
| T-03-07-Path | Tampering | handler `path` arg | high | mitigate | Handlers resolve `path` through the same confined resolution the engine uses; the explore/node disk read stays within the repo root (03-06) |
| T-03-SC | Tampering | mcp-go install | high | mitigate | `mcp-go@v0.56.0` pre-audited OK (pure Go, no CGo, compatible go version) in 03-RESEARCH.md §Package Legitimacy Audit; pinned version, `go.sum` checksum recorded — no `[ASSUMED]`/`[SUS]` package this phase |
</threat_model>
