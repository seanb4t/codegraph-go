<objective>
Implement deterministic lexical symbol search (D-06): `Engine.Query` (full node records) and `Engine.Search` (locations-only), matching over `name` + `qualifiedName` with substring/token matching, `--kind` filtering, and `--limit` capping. Ranking uses a fixed tie-break (exact-name > prefix > substring, then stable sort by qualifiedName/id) so `--json` output is byte-reproducible. No embeddings, no FTS/BM25 score (EMBED-01 deferred; `score` is stripped from the golden as volatile).

Purpose: QRY-01 (`query`) and QRY-03 (`search`) share one matcher and differ only in projection — the full record vs the lightweight location. This is the workhorse behind `query`, `search`, and `explore`'s symbol selection.
Output: `Engine.Query`/`Engine.Search` + matcher + JSON shaping, tested against the fixture graph.
</objective>
