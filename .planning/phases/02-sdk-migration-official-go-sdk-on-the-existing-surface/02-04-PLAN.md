<objective>
Finish SDK-03: get `github.com/mark3labs/mcp-go` out of `go.mod` and re-audit the
resulting dependency closure.

Purpose: plan 02-01 moved the production server to go-sdk but deliberately left
mark3labs in `go.mod`, because four test files outside `internal/mcp` still
import its client and two archtest self-tests still plant its identifiers into
in-memory overlays. Those overlays are the subtle part: both self-tests resolve
the planted import through `packages.Load` and fail loudly if the overlay does
not type-check. The moment mark3labs leaves `go.mod`, both stop proving anything
and start failing for an unrelated reason.

Output: a tree with one MCP SDK in it, two non-vacuity self-tests still able to
fire, and a re-audited dependency closure.

**The measured blast radius**, from `rg -n '"github.com/mark3labs/mcp-go[^"]*"'`
over `*.go` at the start of this phase — nine files carry a real import or
planted-import string, of which plan 02-01 handled five inside `internal/mcp`.
The four remaining client sites are `testdata/golden/golden_parity_test.go`
(in-process client) and the three `test/integration` files (stdio client
transport). Three files carry mark3labs only as a string constant that must
STAY: `internal/cli/archtest/mcp_sdk_confinement_test.go`'s
`forbiddenMCPSDKPrefixes`, `tools/transcriptfreeze/classify.go`'s
`mcpSDKModulePrefixes`, and `internal/mcp/archtest/protocol_version_test.go`'s
`modernSDKPath` table fixture.
