## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| CI release job → published GitHub Release | untrusted downstream users fetch and execute these artifacts |
| GitHub OIDC → cosign cert identity | the signature's trust scope is defined by the workflow ref |
| third-party Actions → build/sign environment | a malicious Action version could tamper with artifacts |
