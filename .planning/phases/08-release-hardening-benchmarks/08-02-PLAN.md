<objective>
Build the pure-logic measurement core of the benchmark harness: OS-level peak-RSS capture with the Linux-KB-vs-macOS-bytes normalization that is this phase's single highest silent-corruption risk (Pitfall 4), plus the json-tagged `Metrics` data holder. Test-first (RED→GREEN) because the normalization is exactly the kind of pure function that must never reach CI wrong — a missed ×1024 produces a phantom 1024× regression/improvement (D-05).

Purpose: This is the foundation the regression gate (Plan 08-06) and the head-to-head runner (Plan 08-07) both consume. It is measured externally so the Go binary and the TS Node binary are compared apples-to-apples (D-05).
Output: `internal/bench` package with proven RSS normalization and the Metrics type.
</objective>
