<objective>
Flip `serve --mcp`'s watcher to default-on and move ALL watcher startup off the MCP handshake path, reworking `internal/cli/serve.go`'s current opt-in `--watch` block.

Implements: D-01 (default ON when hasIndex), D-02 (`--no-watch` opt-out, TS-mirrored help text), D-03 (repurpose `--watch` as force-on — the CLI twin of `CODEGRAPH_FORCE_WATCH=1`), D-04 (`--no-watch --watch` is a hard error via cobra `MarkFlagsMutuallyExclusive`), D-05 (pass explicit flag booleans into the Probe; never mutate process env), D-06 (daemon.New + policy + acquire + watch.Open all move inside the background goroutine — the WATCH-02 guarantee, provable by reading RunE top-to-bottom), D-07 (the reconcile Sync stays synchronous, untouched), D-08a (extract a `serveWatchStart` seam so a mutation-proof structural test pins that RunE genuinely defers all startup, reusing the WR-01 precedent).

The `--no-watch` flag routes through the SAME policy tier-1 check as `CODEGRAPH_NO_WATCH=1` and therefore still emits the verbatim disabled message (RESEARCH Pitfall 2 — do NOT early-return before the goroutine and swallow the message).

Purpose: restore TS's zero-config live-sync experience without ever delaying the handshake.
Output: reworked serve.go (flags + serveWatchStart seam + goroutine wiring + verbatim message), new structural seam test in serve_test.go.
</objective>
