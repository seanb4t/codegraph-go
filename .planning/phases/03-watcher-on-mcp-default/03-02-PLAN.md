Wire WATCH-03's policy into the shared watcher seam and add WATCH-04's defer-and-retry convergence, entirely inside `internal/daemon` so it inherits the package's existing goleak `TestMain`.

Three changes to `internal/daemon/daemon.go`:
1. Give `Daemon` a `watch.Probe` (defaulted by `New`, overridable via a `WithProbe` functional option so `New`'s existing signature — and therefore `internal/cli/daemon.go` — is unchanged), and enforce `watch.WatchDisabledReason` as the FIRST action in `Run`, before `acquire()`, so a policy-disabled watcher never touches the lockfile (D-11, RESEARCH Pattern 2). A disabled policy returns `fmt.Errorf("%w: %s", watch.ErrWatchDisabled, reason)`.
2. Add `RunWithRetry(ctx, d, interval, onDeferred)` (D-14): a thin loop that calls `d.Run`, returns on anything other than `ErrLockLive`, and otherwise invokes `onDeferred` once and sleeps a jittered interval honoring `ctx.Done()`. D-16 is confirmed: `acquire()` self-heals a stale lock on every call, so the loop needs no new staleness machinery.
3. Extend the goleak soak (D-15) with a two-concurrent-session convergence test.

Purpose: one enforcement point for both callers; true single-writer convergence instead of today's "zero watchers after the holder exits".
Output: modified daemon.go, unit tests in daemon_test.go, convergence soak in soak_test.go.
</objective>
