## Cross-AI review findings incorporated (`06-REVIEWS.md`)

Two **class fixes** are applied across every plan in this phase, stated here so the next review
cycle can see they were systematic rather than one-at-a-time:

**Class fix A — tamper guards compare against the pre-plan SHA, never HEAD.**
`git diff --quiet -- <path>` is HEAD-relative, and GSD commits per task, so an earlier task's
COMMITTED change to a protected path is invisible to a later task's guard — the guard goes blind
in exactly the window it exists to watch. Task 1 of this plan therefore records
`git rev-parse HEAD` as the single line of `06-01-PREPLAN-SHA.txt` **before its first edit**, and
every tamper guard in this plan reads that value into `$BASE` and asserts
`git diff --quiet "$BASE" -- <path>`. Every such guard also carries a positive companion
assertion, because a diff-clean check passes vacuously against a file that is absent
(rule `84d1gfpywd`).

**Class fix B — no `rg -c` is used as a "returns no matches" gate.**
`rg -c` exits 1 and prints nothing on the *good* path, so an executor chaining it with `&&` reads
the clean outcome as a failure, and an executor reading exit status leniently reads a broken
command as a pass — the same inverted shape as this repo's documented `rg -qv` incident. Every
such gate is restated as a counted comparison with a printed token, paired with a companion count
that MUST be > 0 so the instrument proves it can still see. `rg -c` used as a FLOOR (`>= 5`,
`>= 1`) or to count line-oriented things is deliberately left alone: `rg -c <= rg -o`, so a floor
is strictly conservative and is not the inverted shape.

**Class fix C — `|| true` is not enough; the count must come from `wc -l`.** (New in cycle 2,
planner-originated, applies to all six plans.) Class fix B's original prescribed form was
`test "$( … | rg -c … || true )" = "0"`. That form is **itself unsatisfiable on the clean path**:
`|| true` repairs the *exit status* but leaves the substitution EMPTY, so the comparison is
`"" = "0"` and fails on correct work. Confirmed in a shell during the cycle-2 replan. This is the
same defect class as cycle-2 HIGH 1 — a guard that fails when the work is right, which trains an
executor to treat red as expected and is how a genuine regression gets waved through. Every such
count is therefore now written as:

```
X=$(<producer> | rg <pattern> | wc -l | tr -d ' ')
echo "TOKEN=$X"; test "$X" = "0"
```

`wc -l` always prints a number and always exits 0, so the zero case is a real `0` and the gate is
satisfiable. Occurrences corrected: `PINDIFF` here; `PERMDIFF` / `FIXDIFF` / `FIGDIFF` and the
inline fixture check in 06-02; `NC` / `CONTENT` / `NONCOMMENT` / `TOLDIFF` / `CATERR` / `SUBS` in
06-03. 06-04, 06-05 and 06-06 were audited and needed none: their only `rg -c` uses are `= "1"`
comparisons fed by a real match, or floors.
