## Version selection

- **golang.org/x/net v0.60.0, not v0.61.0** — v0.60.0 is the fixed version CI's govulncheck names; the minimal
  bump keeps collateral smallest.
- **go 1.26.9** — the fixed stdlib version CI names, and the newest released go1.26.x (go.dev/dl, verified by
  the orchestrator). Set with `go get go@1.26.9`; the planning probe proved this changes exactly the `go` line
  and adds no `toolchain` line.
- **MVS collateral is accepted, not fought.** Live planning probe (`go get golang.org/x/net@v0.60.0` on a
  scratch copy of go.mod/go.sum, 2026-10-12 ~00:45Z) upgraded exactly: x/crypto v0.55.0->v0.57.0,
  x/mod v0.38.0->v0.41.0, x/net v0.58.0->v0.60.0, x/sync v0.22.0->v0.23.0, x/sys v0.47.0->v0.48.0,
  x/term v0.45.0->v0.46.0, x/text v0.41.0->v0.42.0, x/tools v0.48.0->v0.49.0. These are forced: x/net v0.60.0
  requires x/text v0.42.0, whose go.mod requires x/tools v0.49.0, x/mod v0.41.0, x/sync v0.23.0. Module
  versions are immutable and MVS is deterministic, so the executor must see this exact set; any other module
  in the go.mod diff is a STOP-and-report. go.sum grew by 16 lines, none removed. No `go mod tidy` (no CI gate
  requires it, and the 260731-0a0 precedent avoided it for the same reason).
