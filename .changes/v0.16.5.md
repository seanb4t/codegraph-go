## [v0.16.5](https://github.com/seanb4t/codegraph-go/releases/tag/v0.16.5) — 2026-11-07

### Fixes

- codegraph install now records the mise latest link or the Homebrew bin link in place of a versioned path, so agent configurations keep working after a package-manager upgrade.
- Each declaration gets its own node, calls to overloaded methods resolve by arity and argument type or point at the overload set, calls through typed variables resolve, the node count matches the store, and an existing index rebuilds once on its first sync.
- On Linux, the watcher keeps a renamed, moved or quickly re-created directory watched, so changes in it reach the index again.
- A sync that adds a symbol which takes over a name now moves the existing references to it, as a fresh index does.
- The graph UI's location rows carry the overload signature and the ambiguous mark that the CLI and MCP output already show.
- The file watcher adds a directory on any event that names it, because the create event of a directory moved into a watched one does not always arrive on an overlay filesystem.

### Performance

- Reduce the peak memory of a full index by about a quarter, back near its level before one node per declaration
