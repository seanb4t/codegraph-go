# codegraph_explore

Explore relevant symbols: verbatim source, call paths, blast radius.

## Arguments

- `query` (string, required) — Natural-language or symbol/file query.
- `max_files` (integer, optional) — Cap on distinct files returned (default 5).
- `path` (string, optional) — Repo path (default: server cwd).

## Result

Markdown text.
