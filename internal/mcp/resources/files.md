# codegraph_files

Browse the indexed file structure.

## Arguments

No argument is required.

- `depth` (integer, optional) — Directory-nesting cap (0 = unlimited).
- `filter` (string, optional) — Restrict to one language.
- `format` (string, optional) — `flat` (the default) or `tree`.
- `path` (string, optional) — Repo path (default: server cwd).
- `pattern` (string, optional) — Shell glob narrowing the result set.

## Result

Markdown text.
