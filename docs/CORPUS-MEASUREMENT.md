Each best value: calls=58812 (google/guava), extends=2531 (google/guava), implements=1018 (gohugoio/hugo), imports=2160 (gohugoio/hugo), instantiates=1877 (pydantic/pydantic), overrides=4658 (google/guava), references=13063 (google/guava), returns=5591 (google/guava), type_of=11857 (google/guava). Integer division: best/2 floors. The outer clamp max(2, best/2) then min(_, best) is what guarantees every threshold is satisfiable by construction — no kind derives a bar above its own best observed count, so thresholds can never be unsatisfiable, including a kind whose best is 1 (which yields threshold 1, not an impossible 2). D-14's tightening past the non-zero floor is arithmetically unavailable; no kind measured below 2, but the clamp is retained so the rule is uniform and a future single-edge kind would not deadlock. Thresholds are asserted by the locked set; each kind's threshold is <= its best observed count, so the achieved locked set supplies every one. No threshold required the 'best == 1' special case in this run. A kind whose measured count EQUALS its threshold passes — the comparison is at-least (>=), never strictly-greater, and Plan 01-07's guard pins this boundary. Thresholds come from the full eligible universe so selection never feeds the threshold it is judged by; re-running `go run ./tools/corpora -mode select` over the committed observations reproduces these values byte-identically, and Plan 01-06's verify recomputes them independently rather than reading the stored value. The five priority-4 languages deliberately keep the roadmap's non-zero file-count floor rather than a numeric threshold — D-14's threshold decision covered edge kinds only, and a language file-count bar was raised in the phase discussion and left deferred. The overrides and type_of kinds are covered by google/guava's measured 4658/11857 counts; this repository's own idiomatic Go source produces zero of both, so closing them on a named third-party corpus is the entire point of this spike and it is closed with recorded measurement, not expectation.
